# Ansatz discovery playbook

The agent's job is not to guess a circuit name. It is to turn visible
Hamiltonian structure into falsifiable, economical circuit hypotheses, then
let fixed evaluator evidence decide which branches survive.

## Read the Hamiltonian before naming the model

Read `user_problem/hamiltonian.json` directly. File names and `symmetry`
metadata may be useful context, but neither overrides the Pauli terms.

Remember that the rightmost Pauli letter is qubit 0. Separate the identity
coefficient from the active Hamiltonian; the constant moves every energy but
does not select an ansatz. Summarize:

- active term count, coefficient magnitudes and signs, and locality histogram;
- the mix of X-, Y-, and Z-bearing terms and repeated coefficient classes;
- connected components, degrees, boundaries, hubs, and repeated motifs in the
  two-local support graph;
- higher-locality supports that may represent excitation channels;
- the supplied computational-basis occupation and backend connectivity.

Use `uv run autovqe inspect --json` for mechanical graph facts, but keep the
raw terms in view: the compact observation deliberately does not recommend
operators.

## Turn structure into competing branches

Start with the smallest circuit that can test a physical claim. A useful first
round usually contains two genuinely different primary hypotheses, not two
depths of the same template.

### Matchings and dimers

For exchange-like two-local graphs, a disjoint matching tests whether dominant
bonds can gain energy in parallel. Compare boundary dimers, coefficient-ranked
matchings, or a shifted matching when the graph is not uniform. Shared angles
are appropriate only where graph position and coefficients support the same
role.

A matching is a controlled structural probe, not a claim that ignored bonds do
not matter. If it succeeds, revise toward a second covering or a small
boundary/bulk split before adding every edge.

### Boundary-aware layers

Open chains and irregular graphs often distinguish endpoints, bulk sites, hubs,
or leaves. Test a shared bulk parameter plus one boundary class before assigning
one parameter per operation. This exposes whether the optimizer needs spatial
resolution without immediately buying maximum expressivity.

### Hamiltonian variational layers

When the Hamiltonian separates into noncommuting families, try a shallow HVA:
ordered rotations generated by selected cost and mixer terms. Preserve the
observed interaction order. Compare plausible orderings or a smaller selected
term pool; applying all terms is not automatically a better hypothesis.

For diagonal Z structure with transverse X/Y terms, test cost/mixer order and
one layer before adding a second. For general Pauli sums, rank operator groups
by coefficient, support, connectivity, and action on the initial occupation.
Any Pauli rotation above locality two must be an actual Hamiltonian term.

### Phase conditioning and odd-Y channels

A structurally plausible excitation can be objective-flat because the real
initial state, Hamiltonian, and generator have an unhelpful phase relation.
This occurs often enough for Pauli words with an odd number of `Y` letters to
deserve an explicit diagnostic.

Do not treat a flat run as structural falsification until its objective activity
is checked. Test a separately preregistered ordering in which a one-local
noncommuting phase rotation on a participating qubit conditions the excitation.
The placement before or after the excitation is part of the hypothesis. Keep
the phase trainable; never insert a fitted fixed angle.

## Discover and use symmetry

Declared sector metadata suggests probes; it does not certify a conservation
law. Propose an `exact_pauli_symmetry`, request the normalized-commutator probe,
and cite only a supported probe ID.

For U(1)-like particle-number or magnetization conservation, test the relevant
global Z sum or an explicit weighted Pauli sum. `XYExchange` is a compact
number-preserving channel when its cited charge is exact, the input is in a
definite sector, and the gate touches a non-spectator part of that charge.

For SU(2)-like isotropy, examine global X, Y, and Z charges separately; one
commuting component establishes only that component, not full SU(2). An
`IsotropicExchange` can encode exchange structure, but the harness certifies
only cited charges for which the initial state has a definite sector. Do not
overstate a larger symmetry than the available evidence supports.

Symmetry is a search constraint, not the whole ansatz. After identifying a
sector, still use coefficients, graph motifs, initial occupation, locality, and
backend routing to decide which conserving operations and ordering are useful.
Conversely, do not cite a charge merely to gain access to a special gate: all
candidate operations must preserve it and each special gate must be relevant.

## Share parameters structurally

Parameter sharing is a scientific claim that several operations have the same
role. Useful sharing classes include:

- translation-equivalent bulk edges;
- boundary versus bulk sites;
- edges in one matching or coefficient class;
- repeated excitation channels with a justified relative scale.

Allowed relative scales are `-2, -1, -0.5, 0.5, 1, 2`. Use them only for a
clear sign, orientation, or multiplicity relation. If evidence shows a shared
channel is too rigid, split one meaningful class at a time. Do not hide many
independent values as fixed coefficients; every angle remains a zero-offset
multiple of one declared trainable parameter.

## Run a closed research cycle

For each branch:

1. State a physical mechanism and a measurable prediction or falsifier.
2. Submit the smallest typed candidate that isolates it.
3. Run audit and inspect evaluator-owned resource or symmetry violations.
4. Run smoke; distinguish invalid, objective-flat, and genuinely unfavorable
   results.
5. Revise one structural assumption or retire the branch with its evidence.
6. Promote survivors under the fixed protocol and promote a different primary
   structure root as the fair comparator.
7. Commit only a non-dominated result, or close negative only when the required
   objective-active breadth or depth is established.

Keep failed and revised branches. They prevent cycling and make later choices
traceable. Spend budget on discriminating experiments: another copy of the same
ansatz with cosmetic renaming supplies no new evidence and is rejected.

## Common failure modes

- Trusting a problem label instead of the raw Pauli terms.
- Adding every Hamiltonian term before a small motif has shown value.
- Calling a phase-flat branch a physical failure.
- Claiming SU(2) from one U(1) commutator.
- Using conservation gates without supported, relevant sector evidence.
- Giving every gate its own parameter without testing sharing.
- Comparing only variants from the same primary hypothesis.
- Reporting candidate-authored energies, counts, or optimized values.
- Treating local promotion as proof of the exact ground-state energy.
